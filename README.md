# Olympus Siege — website

Public marketing site + privacy policy for the mobile game **Olympus Siege**
(the game's source lives in a separate private repository).

Static HTML, no build step — served via GitHub Pages.

| Page | Purpose |
|---|---|
| `index.html` | Landing page |
| `privacy.html` | Privacy policy (the URL both app stores require) |
| `shop.html` | The Emporium — Divine Pacts web shop (coming soon; will link to a merchant-of-record checkout) |

Icon assets in `assets/` are rendered from the game's canonical brand sheet.
